# Портфолио Таисии Черняховской

Статический сайт-портфолио без сборщика и внешних JavaScript-зависимостей.

## Структура

- `index.html` — семантическая разметка и метаданные страницы.
- `cv.html` — веб-версия резюме со скачиванием PDF и DOCX.
- `assets/css/main.css` — адаптивные стили, темы и анимации.
- `assets/css/cv.css` — стили страницы резюме.
- `assets/js/main.js` — галерея и интерфейсные взаимодействия.
- `assets/js/cv.js` — тема и кастомный курсор страницы резюме.
- `assets/js/image-data.js` — размеры адаптивных изображений.
- `img/` — полноразмерные WebP-изображения.
- `img/s/` — адаптивные версии шириной 600 и 1200 px.
- `img/works/` — новые работы, рассортированные по проектам `bashnya`, `doggo`, `mirabella`, `dayz` и `personal`.
- `img/s/works/` — адаптивные версии новых работ.
- `assets/video/` — видео наружной рекламы «Башни» и Doggo.
- `Tasia_Chernyakhovskaya_CV.pdf` и `Tasia_Chernyakhovskaya_CV.docx` — скачиваемые версии резюме.
- `scripts/build_cv.py` — воспроизводимая сборка DOCX-версии резюме.
- `scripts/import_works.py` — импорт, именование и WebP-оптимизация исходных работ.
- `og.jpg` — изображение для социальных сетей, 1200×630 px.

## Локальный запуск

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Сайт будет доступен по адресу `http://127.0.0.1:8000`.

## Перед публикацией

1. Проверить публичные URL `https://tallety.ru` в метатегах `index.html`.
2. Проверить главную страницу, переключение темы и навигацию.
3. Проверить открытие, увеличение и перелистывание изображений.
4. Проверить страницу `cv.html`, скачивание PDF/DOCX и отображение на мобильном экране.

## Работа с изображениями

При добавлении новой работы нужно сохранить полноразмерный WebP-файл в `img/works/<проект>/`, подготовить версии 600/1200 px в `img/s/works/<проект>/` и обновить метаданные в `assets/js/image-data.js`. Исходные материалы текущего импорта сопоставлены с понятными именами в `scripts/import_works.py`.
